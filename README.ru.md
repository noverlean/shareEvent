# 📍 shareEvent — Telegram-бот для поиска событий в твоём городе

**shareEvent** — это Telegram-бот, разработанный на Spring Boot, который помогает находить интересные события рядом с пользователем. Вдохновлённый концепцией Леонардо Дайвинчика, но с фокусом на мероприятия: вечеринки, квартирники, выставки, театры, клубы и многое другое.

---

## 🎯 Назначение

- 🔎 Поиск событий по типу и городу  
- 📍 Учет геолокации пользователя  
- 🗓️ Категории: вечеринки, театр, концерты, выставки, квартирники и др.  
- 📬 Отправка подборок событий прямо в Telegram  
- 🧠 Возможность масштабирования до рекомендательной системы

---

## 🛠️ Технологии

- Java 17+  
- Spring Boot  
- Spring Data JPA  
- Spring Security  
- Telegram Bot API (через [TelegramBots](https://github.com/rubenlagus/TelegramBots))  
- PostgreSQL  
- Liquibase (для миграций БД)  
- Docker & Docker Compose  
- Maven  
- Lombok
