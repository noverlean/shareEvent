# 📍 shareEvent — Telegram Bot for Discovering Events in Your City

**shareEvent** is a Telegram bot built with Spring Boot that helps users find interesting events happening nearby. Inspired by the concept of Leonardo Daivinчик, but focused on events rather than dating — from nightclubs and apartment parties to theaters, exhibitions, and underground meetups.

---

## 🎯 Purpose

- 🔎 Discover events by category and city  
- 📍 Location-aware recommendations  
- 🗓️ Categories include parties, concerts, exhibitions, theater, apartment gatherings, and more  
- 📬 Event suggestions delivered directly in Telegram  
- 🧠 Scalable toward a full recommendation system

---

## 🛠️ Technologies Used

- Java 17+  
- Spring Boot  
- Spring Data JPA  
- Spring Security  
- Telegram Bot API (via [TelegramBots](https://github.com/rubenlagus/TelegramBots))  
- PostgreSQL  
- Liquibase (for database migrations)  
- Docker & Docker Compose  
- Maven  
- Lombok
